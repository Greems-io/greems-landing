⚡ חדש באפליקציה

עכשיו אתם מחליטים מתי הטעינה מתחילה

הוספנו לאפליקציה טעינה מושהית. מחברים את הרכב כשנוח לכם, קובעים באפליקציה באיזו שעה הטעינה תתחיל, והיא מתחילה בעצמה בזמן שבחרתם. אין צורך לחזור לעמדה ואין צורך לזכור.

איך עושים את זה

1
בוחרים עמדה באפליקציה ולוחצים על Schedule start במקום על Start charging.
2
בלשונית Default hours מחכות לכם שעות ברירת המחדל — התחלה ב-23:00 וסיום ב-17:00. אם זה מתאים, לוחצים Request delayed charging וזה הכול.
3
רוצים שעה אחרת? עוברים ל-Custom hours, בוחרים Today או Tomorrow ואת השעה המדויקת. מסמנים Save as new default charging hours והשעות שבחרתם יחכו לכם גם בפעם הבאה.
תקבלו התראה ברגע שהטעינה מתחילה, כך שתמיד תדעו שהרכב באמת נטען.
